# PhysLab

Video-based physics experiment analyser, built for the Meta Global AI Developer Hackathon (track: Push the Frontier).

Film a simple experiment on your phone (a dropped ball, a pendulum, a bouncing ball). PhysLab tracks the object with **SAM 3.1**, calibrates pixels to metres using a reference object of known size, fits a physics model and reports constants such as g **with uncertainties and pass/fail plausibility checks**. **Muse Spark** classifies the experiment and writes the explanation. Every number comes from deterministic code; the LLM never computes or alters results.

> Status: Phase 0 (setup and Meta Model API client). See `CLAUDE.md` for the full plan.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env   # then set MODEL_API_KEY
```

## Meta Model API usage

`physlab/meta_client.py` follows the official [cookbook](https://github.com/meta-models/meta-model-cookbook):

- Base URL `https://api.meta.ai/v1`, key in `MODEL_API_KEY`, accessed with the OpenAI SDK.
- **Muse Spark** (`muse-spark-1.3`): Chat Completions.
- **SAM 3.1** (`sam-3.1`): streamed Responses API with a noun-phrase concept and an image (data URL) or a video (Files API upload). SAM tracks object identities across the whole video in one request, which keeps API cost low. Output is decoded by the official `meta_sam_parser`.
- All successful responses are cached under `data/cache/`, keyed by model, media content hash and request parameters.
